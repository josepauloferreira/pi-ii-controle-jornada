# Sistema de Controle de Jornada para Trabalho Remoto

Projeto desenvolvido para a disciplina **Projeto Integrador em Computação II** da Universidade Virtual do Estado de São Paulo (UNIVESP).

## Sobre o projeto

O projeto propõe o desenvolvimento de uma solução web para registrar e acompanhar a jornada de trabalho em regime de home office.

### Problema

Como realizar o controle e o registro das horas trabalhadas por colaboradores em regime de home office de forma prática, segura e confiável, garantindo o acompanhamento da jornada de trabalho sem a necessidade de presença física na empresa?

### Objetivo

Desenvolver um sistema web para registrar e acompanhar a jornada de trabalho em regime de home office, permitindo o controle dos horários de entrada, saída e intervalos e facilitando a organização e a consulta dessas informações.
